# ParaTranz2FrostyLoc

Deprecated Windows desktop app for import string from ParaTranz to Frostbite FsLoc chunk.

## About

This project is started at 2024/04/04, for the experiment [Project GW Simplified Chinese](https://gw2.shoushou1106.org/zhcn). It is more like a experiment scratchpad, used to import localized string from [ParaTranz](https://paratranz.cn/projects/9739), convert remaining from Traditional Chinese to Simplified Chinese and write as chunk files, and researching the possibility to expand histogram. With the release of [zyf722/flamethrower](https://github.com/zyf722/flamethrower) contains more comprehensive feature, and the future plan of a open source modding community of Project GW Simplified Chinese, this project was discontinued and repurposed to [Frosty v1 Localization Experience](https://github.com/users/shoushou1106/projects/3), as part of [FlammenwerferPlugin_FrostyV1](https://github.com/shoushou1106/FlammenwerferPlugin_FrostyV1) and [LocalizedStringStudioPlugin](https://github.com/shoushou1106/LocalizedStringStudioPlugin_FrostyV1).

See also: [1.0.6.4_LocPluginTest](https://github.com/shoushou1106/FrostyToolsuite_Legacy/blob/1.0.6.4_LocPluginTest/)
